# SC Tracker for Windows

Download the installer: **[SC-Tracker-Setup.exe](https://github.com/Stratcrowd/sc-tracker-desktop/releases/latest/download/SC-Tracker-Setup.exe)**

The app opens [tracker.stratcrowd.com](https://tracker.stratcrowd.com) in its own window and adds desktop widgets
(Focus timer, Pending tasks, Priority matrix, Sticky notes) from the tray icon. It always shows the live site,
so website updates appear without reinstalling.

## Install

1. Run `SC-Tracker-Setup.exe`.
2. Windows may say "Windows protected your PC" because the installer is not code-signed:
   click **More info**, then **Run anyway**.
3. Open SC Tracker and sign in with your SC Tracker email and password.
4. Right-click the SC icon near the clock to add widgets or turn on Start with Windows.

This repository only hosts releases; the source is private.
